# 3D 카드 링크 서비스 - 제품 요구사항 문서 (PRD)

**프로젝트명**: KingBad 
**목표**: 2시간 내 MVP 완성  
**배포**: Vercel + Supabase  
**타겟**: 데스크톱 사용자 (모바일은 추후)

---

## 1. 프로젝트 개요

사용자가 원하는 텍스트와 카드 컨셉을 선택하면 고유한 단축 URL이 생성되고, 그 링크를 받은 사람이 열었을 때 3D 애니메이션 카드가 팝업되면서 텍스트와 이펙트가 나타나는 서비스입니다.

---

## 2. 핵심 기능

### 2.1 URL 생성 페이지
- **입력 필드**
  - 카드 컨셉 선택 (드롭다운)
    - 축하 (celebration)
    - 우울 (melancholy)
    - 유혹 (seduction)
  - 메인 텍스트 입력 (한글 10자 제한)

- **출력**
  - 단축 URL 생성 (예: `cardpop.vercel.app/c/abc123xyz`)
  - URL은 입력된 텍스트/컨셉을 유추할 수 없는 난수 기반
  - 생성된 URL 복사 버튼

### 2.2 카드 뷰 페이지
링크를 클릭했을 때 보이는 화면. 각 컨셉별로 다른 애니메이션/사운드 재생.

#### 축하 컨셉 (celebration)
**분위기**: 행복, 축하, 기쁨

**비주얼**:
- 배경: 밝은 톤, 축제 분위기
- 선물상자에서 포스트카드가 파티클/스프링 이펙트와 함께 튀어나옴
- 카드 오픈 시 컨페티(색종이) 떨어지는 애니메이션
- 포스트카드가 중앙에 정지되고, 양 옆에 박수치는 사람들의 이미지 표시
- 포스트카드 내부에 사용자가 입력한 텍스트 표시

**사운드**:
- 선물상자 오픈 효과음
- 환호성 또는 빵빠레 사운드

#### 우울 컨셉 (melancholy)
**분위기**: 우울한, 비오는 날씨

**비주얼**:
- 배경: 어두운 톤 (회색/검은색)
- 3D 비가 내리는 애니메이션 (입자 효과)
- 포스트카드가 열리면서 나타남
- 텍스트가 빗방울에 번져서 페이드인으로 서서히 나타남

**사운드**:
- 빗소리 (연속 루프)

#### 유혹 컨셉 (seduction)
**분위기**: 유혹적, 섹시, 관능적

**비주얼**:
- 배경: 장미꽃이 깔려 있는 배경
- 포스트카드가 열리면서 나타남
- 동시에 꽃잎이 흩날리는 애니메이션
- 카드 왼쪽 밖에 유혹하는 장미꽃을 입에 문 아저씨 이미지 표시
- 포스트카드 내부에 텍스트 표시

**사운드**:
- 유혹하는 분위기의 사운드이펙트

## 3. 기술 스택

| 항목 | 선택 |
|------|------|
| **프론트엔드** | React + TypeScript |
| **3D/애니메이션** | Three.js 또는 Framer Motion |
| **백엔드** | Supabase (PostgreSQL + Auth) |
| **호스팅** | Vercel |
| **데이터베이스** | Supabase PostgreSQL |
| **사운드 라이브러리** | Howler.js 또는 Web Audio API |

## 4. 데이터 구조

### Supabase 테이블: `cards`

```sql
CREATE TABLE cards (
  id SERIAL PRIMARY KEY,
  short_id VARCHAR(16) UNIQUE NOT NULL,  -- 단축 URL ID (abc123xyz)
  concept VARCHAR(50) NOT NULL,           -- celebration, melancholy, seduction
  text VARCHAR(10) NOT NULL,              -- 사용자 입력 텍스트 (한글 10자)
  created_at TIMESTAMP DEFAULT NOW(),
  expires_at TIMESTAMP,                   -- 링크 만료일자 (2시간)
  used BOOLEAN DEFAULT FALSE,             -- 사용여부 확인
);
```

## 5. 사용자 흐름 (User Flow)

### 1단계: URL 생성
```
사용자 접속 → 홈페이지
   ↓
카드 컨셉 선택 + 텍스트 입력
   ↓
"카드 만들기" 버튼 클릭
   ↓
Supabase에 데이터 저장 + short_id 생성
   ↓
단축 URL 표시 + 복사 버튼
   ↓
사용자가 URL 공유
```

### 2단계: 카드 뷰
```
링크 수신자 → URL 클릭
   ↓
short_id로 Supabase 조회
   ↓
해당 concept + text 데이터 로드
   ↓
3D 카드 애니메이션 시작
   ↓
사운드 + 이펙트 재생
   ↓
카드 표시 (텍스트 포함)
   ↓
일회용 링크인 경우: used = TRUE로 업데이트
```

---

## 6. 페이지 구조

### `/` - 홈 (URL 생성)
- 헤더: 서비스 로고/타이틀
- 입력 폼
  - 카드 컨셉 선택 (축하/우울/유혹)
  - 텍스트 입력 (한글 10자 제한, 카운터 표시)
  - "카드 만들기" 버튼
- 결과 영역
  - 생성된 URL
  - 복사 버튼
  - 공유 버튼 (선택사항)

### `/c/[short_id]` - 카드 뷰
- 전체 화면 3D 애니메이션 플레이
- concept에 따라 다른 배경/이펙트
- 자동 사운드 재생
- 사용자 입력 텍스트 표시
- "다시 보기" 버튼

---

## 7. 일회용 링크 정책

- 카드 열기 시 자동으로 `used = TRUE` 업데이트
- 만료일자 이후 url 클릭시 "늦어"라는 팝업만 띄우고 카드는 뜨지않음

---

## 8. 구현 우선순위 (MoSCoW)

### MUST (필수)
- [ ] 홈 페이지: 텍스트 + 컨셉 입력
- [ ] URL 생성 로직 + Supabase 저장
- [ ] `/kingbad/[id]` 페이지: 카드 데이터 로드
- [ ] 축하 컨셉 애니메이션 + 사운드 (기본 버전)

### SHOULD (강력히 권장)
- [ ] 우울 컨셉 애니메이션
- [ ] 유혹 컨셉 애니메이션
- [ ] 반응형 버전 (데스크톱 먼저)

### COULD (여유 있으면)
- [ ] 일회용 링크 로직
- [ ] 사용자 통계 (조회수)
- [ ] AI 커스텀 컨셉 생성 (향후 기능)

### WON'T (제외)
- [ ] 모바일 반응형 (추후)
- [ ] 사용자 인증 (추후)
- [ ] 카드 수정 기능 (일회용 서비스)

## 9. 애니메이션/이펙트 명세

### 공통
- 카드 오픈: 팝업 효과 (0.5초 ~ 1초)
- 텍스트 페이드인: 0.3초 ~ 0.5초

### 축하
- 파티클 이펙트: 선물상자 중앙에서 분사
- 컨페티: 위에서 아래로 내려옴 (2초)
- 박수치는 사람: 양쪽 끝에 정적 이미지

### 우울
- 비 입자: 위에서 아래로 지속
- 텍스트 번짐: 약간의 블러 + 페이드인

### 유혹
- 꽃잎: 바람 효과로 흩날림
- 아저씨: 왼쪽 끝에 정적 이미지
- 립스틱, 목걸이: 3D이미지로 오른쪽끝에 둥둥 띄워져 있는 효과로 있음
