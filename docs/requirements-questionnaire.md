# 3D 카드 링크 서비스 - 요구사항 정의 질문지

2시간 내 완성을 위한 핵심 요구사항을 정합니다. 각 항목에서 선택하거나 기입해주세요.

---

## 1. 카드 컨셉 / 디자인

- [ ] **사전 정의된 템플릿** (예: 생일축하, 고백, 응원, 졸업축하 등)
  - 몇 개의 템플릿이 필요한가? `3`개로, 컨셉은 축하/우울/유혹이야 
  
- [ ] **사용자 커스텀 (배경색, 이모지만 선택)**
  - 커스터마이징 옵션: 사용자는 커스텀 할 수 없고 텍스트만 입력할 수 있음 

- [ ] **카드 스타일**
  - 열기 방식: 팝업

---

## 2. 텍스트 콘텐츠

- 텍스트 입력 길이 제한:
  - [ ] 한글 10자

- 입력 가능한 필드:
  - [ ] 메인 텍스트만 입력 가능

---

## 3. 3D 애니메이션 & 효과

- **카드 열기 애니메이션**:
  - 복잡도:  [ ] 복잡 (고급 이펙트)

- **텍스트 나타나는 방식**:
  - 컨셉에 따라 다름
    [ ] 축하컨셉 템플릿: 선물상자에서 포스트카드가 파티클/스프링 이펙트와 함께 튀어나오면서 카드가 열리고 텍스트가 나타나야함, 카드가 열리면 컨페티가 떨어지며 포스트카드가 중앙에 보이는데 양 옆에 박수치는 사람들이 이미지로 나와야함, 사운드로 환호성 또는 빵빠레가 울려야함 (행복, 축하, 기쁨 분위기)
    [ ] 우울컨셉 템플릿: 배경이 어두운 톤에 비가 3D로 내리고 있어야함, 사운드도 비내리는 소리가 있어야함, 포스트카드가 열리면서 텍스트가 그 안에 나타나는데 텍스트가 비에 번져서 페이드인으로 서서히 나타나야함 (우울한분위기)
  - [ ] 유혹컨셉 템플릿: 장미꽃이 깔려있는 배경에서 포스트 카드가 열리면서 텍스트가 나타나는데 카드가 열리면서 꽃잎이 흩날려야함. 그리고 동시에 옆에 유혹하는 장미꽃을 입에 문 아저씨가 카드 밖 왼쪽에 보여야함. 유혹하는 사운드 포함. (유혹, 섹시, 관능적인 분위기)

- **배경 효과**:
  - [ ] 입자효과 음향효과 등등 각종 효과 다양하게 자유롭게 알아서
